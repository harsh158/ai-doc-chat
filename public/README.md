# AI Document Chat

An AI-powered document Q&A app that lets you upload PDF or TXT files and ask questions about them.

## Features
- Upload PDF or TXT documents
- AI answers questions based on your document
- Smart chunking (RAG) for accurate answers
- Clean dark chat UI

## Tech Stack
- Node.js + Express
- Groq API (Llama 3.1)
- PDF.js for PDF parsing
- Deployed on Railway
